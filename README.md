# 💻 Trilha de Estudos Front-End (Básico ao Avançado)

Este repositório é dedicado exclusivamente à **prática e consolidação de conhecimentos**, cobrindo a evolução nos estudos de front-end — desde os conceitos fundamentais do HTML/CSS até recursos avançados de animações e JavaScript.

---

## 📌 Conteúdos em Prática

### 🎨 CSS (Básico ao Avançado)
- **Fundamentos:** Reset CSS, estilizadores base, pseudo-elementos e regras de Z-Index.
- **Layouts:** Flexbox e CSS Grid Layouts para estruturação de interfaces.
- **Efeitos e Animações:** Transformações 2D, Transformações 3D e Animações CSS.
- **Design Adaptável:** Práticas de responsividade para diferentes tamanhos de tela.

### ⚡ JavaScript & Manipulação de Mídia
- **Lógica e Módulos:** Funções auxiliares, importações e estrutura de scripts (`main.js`, `prime.js`).
- **Práticas Web:** A pasta `web/` contém testes focados na aplicação de JavaScript no ambiente web (como manipulação de DOM e consumo da PokéAPI).
- **Mídia:** Testes de integração de áudio (`.mp3`), vídeo (`.mp4`) e imagens.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica de páginas e tags de mídia.
- **CSS3:** Estilizações, layouts modernos (Flex/Grid) e animações.
- **JavaScript (ES6+):** Manipulação dinâmica de elementos e testes para web.
