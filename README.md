# Front-end Básico DIO 🚀

Repositório criado para armazenar os exercícios, projetos e conceitos práticos aprendidos durante os módulos de fundamentos de Front-end na **Digital Innovation One (DIO)**.

---

## 📌 Conteúdos e Conceitos Abordados

Neste repositório você encontrará exemplos práticos de:

- **HTML5**: Estruturação de páginas, uso de mídias (`audio`, `video`, `image`) e semântica.
- **CSS3**:
  - Estilização básica e reset de estilos (`reset.css`).
  - Layouts modernos (**Flexbox** e **CSS Grid Layout**).
  - Design responsivo (Media Queries).
  - Animações e transformações (2D e 3D).
  - Pseudo-elementos e controle de sobreposição (`z-index`).
- **JavaScript**: Lógica de programação e conceitos básicos (ex: verificação de números primos).
