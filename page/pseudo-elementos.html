Pseudos-elementos

Usado para adicionar elementos extras, sem a necessidade de declara-lo no HTML, ou para selecionar uma parte de algum elemento.

Identificando por ::palavra-chave

Pseudo-elemento - ::first-letter

seleciona aprimeira letra da primeira linha

Propriedades disponiveis:
  • color
  • background
  • margin
  • padding
  • border
  • font
  • Propriedades de texto
